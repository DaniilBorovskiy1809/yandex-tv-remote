## Идеи, которые не стоит делать

- ADB-пульт: требует авторизации и не является пользовательским сценарием.
- Google TV Remote protocol: в `monet` нет сервиса.
- Root-эксплойты: не нужны для HID.
- Обход сопряжения: TV не принимает команды без канала.

## Критерии готовности

Релиз считается стабильным, если:

1. CI собирает APK без ошибок.
2. На реальном `monet` работают все кнопки HID.
3. Переподключение после выключения ТВ не требует переустановки.
4. ИК-режим корректно disabled на телефонах без передатчика.
5. TalkBack проходит основные сценарии.
6. Нет ANR при удержании кнопок.
