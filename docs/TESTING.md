# Тестирование

## 1. Что проверять в первую очередь

### 1.1. Сборка

- GitHub Actions `Build APK` завершается успешно.
- Артефакт `yandex-tv-remote-debug` содержит `app-debug.apk`.
- APK устанавливается на телефон без ошибок.

### 1.2. Bluetooth HID

1. Включить Bluetooth.
2. Выдать `BLUETOOTH_CONNECT` и `BLUETOOTH_ADVERTISE`.
3. Нажать «Сделать видимым».
4. На телевизоре открыть **Настройки → Пульты и аксессуары → Добавить аксессуар**.
5. Найти телефон, создать сопряжение.
6. Проверить статус «Подключено».

Проверить кнопки:

- [ ] Power (телевизор включён)
- [ ] TV
- [ ] Settings
- [ ] Voice (открывает голосовой ввод ТВ)
- [ ] D-pad Up/Down/Left/Right
- [ ] OK
- [ ] Back
- [ ] Home
- [ ] Menu
- [ ] Volume +/−
- [ ] Mute
- [ ] Channel +/−
- [ ] Play/Pause
- [ ] Previous/Next
- [ ] Rewind/Fast Forward
- [ ] Stop
- [ ] Record
- [ ] Guide
- [ ] Search
- [ ] Digits 0–9

Проверить удержание:

- [ ] D-pad повторяется
- [ ] Volume повторяется
- [ ] Channel повторяется
- [ ] Rewind/Fast Forward повторяются
- [ ] Power не повторяется
- [ ] Цифры не повторяются

### 1.3. Переподключение

- [ ] Выключить и включить Bluetooth на телефоне → приложение восстанавливает HID-профиль.
- [ ] Выйти из приложения и вернуться → профиль не перерегистрируется лишний раз.
- [ ] Выключить телевизор → статус меняется на «Готов к подключению».
- [ ] Включить телевизор → телефон подключается или требует повторного сопряжения.
- [ ] Забыть устройство на телевизоре → приложение показывает «Готов к подключению».

### 1.4. Разрешения

- [ ] Первый запуск: запрос Bluetooth-разрешений.
- [ ] Отказ → статус «Нужны разрешения Bluetooth», кнопка «Разрешить Bluetooth».
- [ ] Повторный запрос после отказа.
- [ ] Bluetooth выключен → кнопка «Включить Bluetooth» открывает системный диалог.
- [ ] Android 9–11: разрешения не запрашиваются, HID работает.

### 1.5. ИК

- [ ] На телефоне без ИК-передатчика ИК-режим disabled и показывает предупреждение.
- [ ] На телефоне с ИК-передатчиком режим включается.
- [ ] «Проверить ИК» отправляет Power.
- [ ] Кнопки без ИК-кода disabled.
- [ ] Кнопки с ИК-кодом отправляют NEC-кадр.

## 3. Проверка HID-дескриптора

Если кнопки не работают:

1. Проверить, что телефон вообще появился в списке Bluetooth-устройств телевизора.
2. Проверить, что сопряжение завершилось.
3. Проверить, что в приложении статус «Подключено», а не «Готов к подключению».
4. Проверить, что телефон не использует другой HID-профиль (например, клавиатуру другого приложения).
5. Перезапустить приложение и HID-профиль кнопкой «Повторить».

Если работают только цифры:

- значит, клавиатурный report проходит, а consumer report — нет;
- проверить дескриптор Report ID 2 и длину отчёта (2 байта);
- проверить, что `sendReport` возвращает `true`.

Если не работают только отдельные кнопки:

- usage может не маппиться в `Generic.kl`;
- заменить на более совместимый usage (например, `0x223` вместо `0x172`);
- проверить `Generic.kl` на телевизоре.

## 4. Проверка NEC

Осциллограф/ИК-приёмник не обязателен. Можно проверить косвенно:

1. Навести телефон на телевизор.
2. Нажать «Проверить ИК».
3. Если телевизор выключается/включается — NEC-путь работает.
4. Если нет — проверить:
   - есть ли `hasIrEmitter()`;
   - не закрыт ли ИК-порт чехлом;
   - расстояние 1–3 м;
   - не мешает ли яркое солнце/лампы;
   - активен ли NEC-декодер в обычной загрузке.

## 5. Accessibility

- [ ] TalkBack читает названия кнопок.
- [ ] Кнопки имеют `Role.Button`.
- [ ] Disabled-кнопки объявляются как disabled.
- [ ] Контраст текста достаточен в светлой и тёмной темах.
- [ ] Размер кнопок не меньше 48 dp.
- [ ] UI не ломается при системном шрифте 200%.

## 6. Регрессии

При изменении `RemoteKey` проверить:

- [ ] Все кнопки отображаются.
- [ ] Все кнопки имеют `labelRes`.
- [ ] В ИК-режиме disabled только те, у которых нет `ir`.
- [ ] Повтор не срабатывает на Power/цифрах/OK.
- [ ] Snackbar не перекрывает пульт.

## 7. Автоматические тесты

JVM-тесты лежат в `app/src/test/java/`:

| Файл | Что проверяет |
|---|---|
| `NecEncoderTest` | длина кадра, leader, порядок бит, адрес, команда, инверсная команда, невалидные значения |
| `HidReportsTest` | keyboard report, consumer little-endian, release-отчёты, report ID, невалидные usage |
| `RemoteKeyTest` | label и HID у каждой кнопки, покрытие и диапазон ИК-кодов, диапазоны usage, повторяемые кнопки, ключевые маппинги |

Запуск:

```bash
./gradlew testDebugUnitTest
```

HTML-отчёт:

```text
app/build/reports/tests/testDebugUnitTest/index.html
```

Тесты не требуют Android-устройства: NEC-кодирование вынесено в `NecEncoder`, HID-отчёты — в `HidReports`. Это позволяет проверять протоколы на JVM.
